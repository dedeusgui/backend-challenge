# Requirements matrix

Traceability between [challenge specification](CHALLENGE.md) and this
implementation. Section numbers refer to `docs/CHALLENGE.md`.

Status values: `NOT_STARTED`, `IN_PROGRESS`, `PASSING` (proven by a
test or verification performed), `BLOCKED`. A line is `PASSING` only when the listed test command was run and passed. Update this file in the same
commit of the slice that changes a line.

`bun run check:financial-invariants` supplementary checker runs SQL queries in a read-only transaction
for financial invariants `INV-01` to `INV-11` and structural checks `DB-01` to `DB-11`; `INV-12` is informational only. It checks the state and structure visible in the database,
but it does not alone prove the use of `Money` in TypeScript, the absence of a global lock or publication after commit. Consult
[invariant review](INVARIANT_REVIEW.en.md) for scope and limits. The presence of the command in this documentation
does not mean it was executed on the current HEAD.
